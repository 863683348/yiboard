## OD-1｜多棋种路线图：品类扩张顺序与验证闸门

### 背景
产品核心假设是 **VP1「一个账号玩遍中国棋」**（五子棋 → 象棋 → 黑白棋 → 围棋，统一段位/好友/复盘）。
当前仅上线五子棋（含好友房/排行榜/每日残局/棋谱库）。"多棋种聚合"是全站差异化叙事（对 Gomoku.com 单品类、Xiangqi.com 单品类、OGS 单围棋的结构性差异），但也是 MVP 后最大的投入面，必须按数据分阶段扩张，且有可证伪的熔断闸门。

### 已规划的扩张顺序（源自产品规划 §6 / 技术架构 §3.2）

| 次序 | 棋种 | 时间窗 | 实现路径 | RICE | 备注 |
|---|---|---|---|---|---|
| 1 | **象棋 Xiangqi**（人机 + 在线） | Phase 1 M1.1（第 5–7 周） | 集成 **XQWLight**（约 1500 行 C，Emscripten → WASM，含开局库/置换表）；备选 ElephantEye（更强但体积大） | 2.7（战略权重 > RICE） | **唯一验证器**：象棋对局占比是 VP1 判据；统一段位体系须打通 |
| 2 | **Renju 禁手模式** | Phase 1 M1.2（第 7–9 周） | 五子棋规则上加禁手判定（服务端权威） | 3.2 | 承接硬核连珠玩家，抵御 Gomoku.com 已上 Renju 的正面竞争 |
| 3 | **黑白棋 Othello** | Phase 2 M2.1（第 4–6 月） | 复用 Gomoku 引擎框架换评估函数 | 2.1 | **先于围棋**：规则简单、引擎轻、海外认知度高（全球经典棋类） |
| 4 | **六子棋 Connect6** | Phase 2 M2.1（第 4–6 月） | 同上，换评估函数 | — | 低成本品类补齐 |
| 5 | **围棋 Go** | Phase 2 M2.1（第 4–6 月，最后） | **优先对接而非自建**：KataGo 需 GPU，路径① 外部 GPU 推理服务（Replicate/自建）做 AI 复盘；② 接 OGS API 跳转/联合登录 | 0.8 | Effort 最高、Confidence 最低；赛道已被占，价值在"品类完整性叙事" |

### 验证闸门（熔断条件，不可跳过）
- **Phase 1 出口**：象棋对局数 / 总对局数 **≥ 8%**（Exit Criteria 主指标）
- **熔断**：象棋对局占比 **< 3%** → "多棋种聚合"假设不成立 → **立即停止横向扩品类**，转向"五子棋深度 + 竞技生态"单品类路线，Phase 2 全部重排
- **Phase 2 出口**：非五子棋对局占总对局 **≥ 30%**
- **熔断**：非五子棋占比 **< 15%** → 平台化失败，接受"五子棋垂直站"定位，砍掉长尾棋种维护成本

### 技术前置（架构已就绪）
- DB：`game_type ENUM ('gomoku','renju','xiangqi','connect6','othello','go')`，ratings 每用户每棋种一行
- 匹配：MatchmakerDO 每 `gameType+mode` 一个队列（`mm:gomoku:ranked:AMER` 模式）
- 规则层：`src/rules/` 各棋种纯函数无副作用
- 引擎策略：**永不自研**（XQWLight/Elephant/KataGo 开源已够）

## OD-2｜10 语路线图：从 5 语扩至 10 语

### 背景
竞品 Gomoku.com 用 **15+ 语言**吃全球自然量（上线首年 402 万盘对局）。"语言即 SEO 覆盖面"已验证：i18n 架构 Day 1 铺好，后补即重构。
当前已实现 **5 语**：en（默认）/ zh / es / ja / pt-BR（next-intl，localePrefix as-needed，增删语种零改路由）。
规划目标：Phase 1 M1.4（第 11–13 周）**扩至 10 语**，选语依据 **MVP 期 GA 国家分布数据**（RICE 7.0，边际成本最低的增长杠杆）。

### 已决 / 现状
- **D7 首批 4 语**（产品规划中"待确认"、技术架构中"已锁定"）：**EN / ES / JA / PT-BR**；中文不做出海 SEO 主推（避免华人用户过早涌入拉偏方向），但已提供中文界面
- 非中文界面会话占比目标：Phase 0 ≥ 60% / Phase 1 ≥ 60%（全球化 KPI）

### 扩语增量候选（按 GA 数据命中率预排）
| 候选语种 | 依据 | 优先级 |
|---|---|---|
| 德语 de | 欧洲棋类用户量大、Gomoku.com 已铺（2026-03 起德语先上） | 高 |
| 法语 fr | 同上，欧洲主力 | 高 |
| 意大利语 it | Gomoku.com 已铺（2026-03 密集上线意/俄/泰/葡/波） | 中 |
| 俄语 ru | Gomoku.com 已铺 | 中 |
| 波兰语 pl | Gomoku.com 已铺 | 中 |
| 泰语 th | 东南亚棋类热度 | 中 |
| 韩语 ko | 五子棋（오목）本土认知极强 | 高（但需与 GA 数据交叉验证） |
| 越南语 vi | Xiangqi.com 已验证（SC/TC/EN/VI） | 中 |
| 土耳其语 tr / 印尼语 id / 印地语 hi | 用户规模大、竞争弱 | 待数据 |

### 落地方式
- 每语种 = `messages/{locale}.json` 全量文案 + `[locale]` 路由自动生效（架构零改动）
- 每语种同步生成：首页 / 玩法 / 规则页 / 残局 / 棋谱库 / 排行榜 / 博客文章（**SEO 页面 × 语种**批量覆盖，页面数量换收录面）
- 每语种需本地化校验（非机器翻译直出，至少母语者 review 关键页）
